# 测量卫生清单（开跑前 1 分钟）

> 背景程序会污染测量，而且**大部分污染不会报错**——只会让某一格"莫名变慢"。
> 这份清单的每一条都对应一种真实机制，不是洁癖。

---

## 一、三种污染机制（按杀伤力）

| # | 机制 | 谁在污染 | 后果 |
|---|---|---|---|
| **①** | **显存被占** | 别的 DSH 会话（自己也起 llama-server）、浏览器硬件加速、游戏、动态壁纸 | 把格子推过悬崖阈值 → llama.cpp **静默 KV offload**，慢 **2.6–4.3 倍**且不报错 |
| **②** | **显存带宽争用** | 视频播放、浏览器、动态壁纸、音乐可视化 | 直接压低拟合出的**有效带宽 BW**（我们报的是 249.1 = 标称 92%，被争用会更低） |
| **③** | **SM 抢占 + 帧节奏** | 游戏、壁纸引擎、其他推理进程 | 抬高**尾部延迟**（p90/p99），让 SLA 分析失真 |

**最危险的是 ①**：它不报错，只让数字变难看，而你很可能把它当成"模型不准"。

---

## 二、开跑前必须关掉的

| 程序 | 为什么 | 级别 |
|---|---|---|
| **别的 DSH 会话** | 可能已起 llama-server → 抢显存 + 抢 8090 端口 + 抢 CPU | 🔴 必关 |
| **游戏 / 游戏启动器** | 显存 + SM + 带宽三重争用；启动器还有后台更新 | 🔴 必关 |
| **浏览器（硬件加速）** | 视频/动图持续上传纹理，吃带宽；多标签页吃显存 | 🟠 建议关 |
| **动态壁纸（Wallpaper Engine）** | 持续渲染，吃 SM 与带宽 | 🟠 建议关 |
| **QQ 音乐 / 各类可视化** | 频谱动画持续占 GPU | 🟡 关掉可视化即可 |
| DSH 本身（本会话） | 只在需要时跑，别同时开别的长任务 | 🟡 注意 |

## 三、一句话体检（开跑前必做）

```powershell
$py = "D:\llm\venv\Scripts\python.exe"
cd C:\Users\王钟垚\Desktop\find_career\tokencost\code
& $py tc.py gpucheck
```

**判定标准**

| 结果 | 含义 | 怎么办 |
|---|---|---|
| `bg_mem < 500 MB` 且 `util p95 < 5%` | 背景干净 | ✅ 直接开跑 |
| `bg_mem 500–1200 MB` 或 `util ≥ 5%` | 轻度占用 | ⚠️ 结果可用，尾部可能偏高；建议先关 |
| `bg_mem ≥ 1200 MB` | 有重负载 | 🔴 关掉再跑 |

> Windows 桌面本身约占 200–400 MB，属正常基线。

## 四、自动化：每一格已经自带背景记录

从 `2026-11-04` 起，`tc_run_cell.py` 在**起服务之前**采样一次，把四个字段写进 `raw_cells.jsonl`：

| 字段 | 含义 |
|---|---|
| `bg_mem_mb` | 当时显存已用（含桌面） |
| `bg_util_p95` | 空载利用率 p95 |
| `bg_clock_mhz` | SM 时钟（空闲态低是正常的） |
| `bg_level` | `ok` / `warn` / `bad` |

**这样"当时有没有别的程序在跑"就成了数据的一部分**，而不是靠回忆。
被污染的格可以按 `bg_level != 'ok'` 筛出来单独看。

> 之前的 362 行没有这几个字段（那时还没加），值为空——**说明未知，不等于干净**。

## 五、如果怀疑某格被污染，怎么验证

选同一格跑 A/B（约 10 分钟）：

```powershell
# A：清空背景后跑 3 轮
& $py tc.py gpucheck
& $py tc_run_cell.py 7B q4_k_m 2048 4 --repeats 3

# B：故意开着浏览器/壁纸，再跑 3 轮
& $py tc_run_cell.py 7B q4_k_m 2048 4 --repeats 3
```

**判读**：TTFT/TPOT 中位数差 **<2%** → 可忽略；**>5%** 或 `mem_used` 差 >300 MB → 确认有影响，那批数据要标注。

## 六、为什么这条值得写进文档

因为它是**唯一一类"看起来数据坏了、其实是环境坏了"的错误**。
本项目已经踩过同型的坑：显存边界不是硬墙而是悬崖（F2）——
**那次也是"不报错，只是变慢"**。

> **判据**：如果一个数字突然变差而原因不明，先查环境，再查模型。
