# 测量纪律：22 条失败记录，以及它们沉淀成的机制

> 这个项目对外报的是 `8.58%`。但真正让它可信的不是这个数字，
> 而是**它被推翻/改写过 22 次，每一次都留下了痕迹和一条防线**。
>
> 本文把 `失败与修复记录.md` 里的 22 条事故提炼成**四条原则**和**一张机制表**。

---

## 一、四条原则（全部由事故倒逼）

### 原则 1：**先怀疑测量，再怀疑模型**

| 事故 | 表面现象 | 真相 |
|---|---|---|
| F7 | 应用题准确率"全员 2%" | **题目答案写错了**（`a+b*c` 应为 `a-b*c`） |
| F9 | TTFT 只有 13.6 ms（≈一个 token 的时间） | **测的是 prompt 缓存命中**，不是 prefill |
| F15 | 复算 MAPE 11.28% vs 官方 8.58% | **读错了成本列**（墙钟 vs 稳态） |

三次的共同点：**模型没坏，是尺子坏了。**
判据很朴素——**"快得离谱"或"差得离谱"本身就该触发一次测量复核。**

### 原则 2：**一个"看起来合理"的数字，可能只是另一套口径的正确答案**

F15 里 11.28% 不是随机错，它**正好是我们公布的墙钟口径数字**。
F10 里 55 ms 的 TPOT 也不是随机错，它**把 HTTP 收尾算进了每 token 时间**。

> 所以"数字落在合理区间"不能作为正确性的证据。
> **能对上独立算出的官方值，才是证据。**

### 原则 3：**检查器本身也要被检查**

| 事故 | 检查器怎么失效的 |
|---|---|
| F12 | 补丁脚本"没命中"也打印成功 |
| F13 | 两种混合共用 `_mix` 后缀 → 后者覆盖前者的身份 |
| F14 | 多轮分支算完**从不落盘**，屏幕一切正常 |
| 复核第 13 轮 | 检查器把期望值写死成旧值 → **写旧值反而判通过** |
| 复核第 13 轮 | `.get(不存在的键, "")` 返回空串 → **检查项变成空操作** |
| 复核第 13 轮 | 生成物里有 `nan%`，`--check` 仍报 OK（只扫字典、不扫产物） |

六次里有三次**同一个病根**：**没有断言的地方，就会静默失效。**

### 原则 4：**让"环境"进入数据，而不是进入记忆**

| 事故 | 沉淀成的字段/机制 |
|---|---|
| F2（显存悬崖） | `kv_fits_vram()` 判定 + 显存预警闸门 |
| F10（批次双峰 8.4%） | 每格记录 `bg_*`、按 `repeat` 回退切批 |
| 时钟漂移（c5–c8 低 8%） | `clock_ratio` / `clock_gate`（相对可达参考，而非标称 3105 MHz） |

> "当时有没有别的程序在跑""那批是不是热了"——**这些不能靠回忆，必须写进原始数据。**

## 三、现在这套防线（8 步 CI，全自动）

| 步 | 检查 | 它防的是哪一类 |
|---|---|---|
| 1 | 重新生成 `CLAIMS.md` | 数字漂移 |
| 2 | `claims --check`：必须出现最新值 + 禁止旧值 | **写死期望值的假检查**（第 13 轮） |
| 3 | 单元测试 + **护栏测试（5 项）** | 静默失效（F12/F13/F14 + 键名/nan） |
| 4 | 文档数字 lint（作废值黑名单） | 旧数字残留 |
| 5 | 全项目体检（14 项，含裸克隆自包含） | "本机能跑、换机就废" |
| 6 | 自标定链路自检（合成数据） | 标定代码坏掉 |
| 7 | 静态计算器与产物一致 | 网页过期 |
| 8 | 数据字典与产物一致 | 文档过期 |

## 四、还靠人的部分（诚实清单）

## 五、三句话（面试可直接用）

1. **"我的模型被数据推翻过 22 次、也留了 22 次记录，每次都留着记录——包括我自己两次把检查逻辑改坏的记录。"**
2. **"每次事故都变成了一条机制：要么是闸门（显存/时钟/背景），要么是测试（5 条护栏），要么是文档口径（数据字典）。"**
3. **"所以我报 8.58% 时会同时说三件事：随机划分是 9.1–13.9%、中间并发要 ×1.2–1.3、高并发尾部偏乐观 2 倍。"**

## 附：为什么这比"我们做得很好"更有说服力

一个人说"我的模型误差 8.58%"，你无法判断他是**真的测了**还是**挑了个好数字**。
一个人说"8.58%，随机划分能到 12.3%，中间并发会差 20%，高并发尾部偏乐观 2 倍，
而且这是我第 22 次推翻自己的记录"——**你能判断他测过。**

> **可验证性不是"结果好看"，是"错误可见"。**
