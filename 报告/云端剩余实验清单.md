## P0 · 能把结论从"提示"变"机制"（最值钱）

### ① 逐请求抖动，两栈各跑一次（约 30 分钟）

**要回答**：F16/F17 猜的"prefill 打断 decode 的排队效应"是否成立。

若成立应看到：
1. 同格内 TPOT 的 CV 随并发上升；
2. **两个栈都上升**（否则只是某栈的实现细节）；
3. 抖动幅度与 TTFT 的系统性偏差同向。

```bash
# 先起好服务（llama.cpp 8092 / vLLM 8081，见手册 §10）
cd /mnt/workspace/tc_a10/tokencost/code

python3 tc_measure_jitter.py --base-url http://127.0.0.1:8092/v1 \
  --backend llamacpp --concs 1,4,8,16,32 --length 1900 --gen 128 \
  --hardware "A10 24GB / llama.cpp" --out /mnt/workspace/tc_a10/results/jitter_a10_llamacpp.json

python3 tc_measure_jitter.py --base-url http://127.0.0.1:8081/v1 \
  --wire-model qwen3b --backend vllm --concs 1,4,8,16,32 --length 1900 --gen 128 \
  --hardware "A10 24GB / vLLM" --out /mnt/workspace/tc_a10/results/jitter_a10_vllm.json
```

**回本地后**：`python code/tc.py jitter` 已能读本机逐请求数据；这两份新数据我会另写合并分析。

### ② V100 带宽阶梯第三点（约 40 分钟）

**要回答**：`TPOT ∝ W/BW` 在 **249 → 472 → ~700 GB/s** 上是否线性。
这是"拟合出的 BW 是物理量而不是补丁参数"最直接的一击。

```bash

HW_LABEL="V100 16GB" bash scripts/a10_run.sh llamacpp
```
