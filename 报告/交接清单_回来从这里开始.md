| **抖动随 prompt 长度放大** | `CV(c32) ∝ L^0.6`：L=64 **3.3%** / 256 **7.2%** / 1900 **25.9%**；低并发与长度无关 | 附录 §5.27、`results/a10_raw/jitter_a10_vllm_L*.json` |
| **前缀复用（多轮 TTFT 高估的机制）** | `cache_prompt=false` 时同 prompt 重复 TTFT **−31%**（对照组 −0.5%）；`=true` 时 **−94%**（405→24 ms） | 附录 §5.26、`prefix_a10_llamacpp_{off,on}.json` |
| **混合长度在 vLLM** | 逐请求误差 **121%**（与 llama.cpp 的 121%/146% 同量级）→ **跨栈失效** | 附录 §5.24、`mixed_a10_vllm.json` |
| **多轮在 vLLM** | TTFT 误差仅 **−3~−13%**（llama.cpp 是 +30~47%）→ 差异来自前缀缓存 | 附录 §5.25、`turns_a10_vllm.json` |

| **T4 第 4 点未做** | 免费额度不含 T4；T4 的 320 GB/s 落在既有区间内部，边际价值最低 | 附录 §5.23 末尾 |

| **SLA 方差律** | `CV = 1.09% + 1.21e-4·(b-1)^0.52·L^0.78`（R²=0.994）；对数正态形状误差 0.8%；样本外 136 格 MAPE **6.8%**（常数假设 9.8%）。**极端尾部仍低估 → 是下界不是上界** | 附录 §5.29、`results/tail_variance.json` |
| **`c_srv` 拆解** | 采样 **+0.04 ms/步**、logprobs **+0.37 ms/步**、SSE 推流 **−18.5 ms（流式更快）** → `c_srv` 不在这些地方，只剩**调度/批处理记账** | 附录 §5.30、`components_a10_vllm.json` |
