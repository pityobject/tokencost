## 1. 问题（150 字）

大模型的 decode 阶段每生成一个 token 都要把全部权重从显存读一遍，因此推理成本主要由**显存带宽**与**算力**这两个机器常数决定。工程上真正要回答的问题是：

> 给定延迟 SLA 与质量底线，在什么（模型规模, 量化档位, 上下文上限, 并发数）组合下，单位 token 成本最低？

[写一句你的动机：为什么关心"单位成本"而不是"tokens/s"]

## 2. 方法（250 字 + 两张公式）

### 2.1 解析模型

```
TPOT(b) = max( (W + KV(ctx)) / BW ,  2·P·b / PEAK ) + ovh
TTFT(L) = max( W / BW ,  2·P·L / PEAK ) + ovh
拐点    b* = w · PEAK / (2 · BW)
```

仅三个待定参数：有效带宽 `BW`、有效算力 `PEAK`、固定开销 `ovh`。
参数个数与标定样本数之比为 1:4。

### 2.2 标定与检验

- 标定集：______ 个配置（实验设计：覆盖各维度的极端与中心）
- 留出集：______ 个配置（**绝不参与拟合**）
- 损失函数：对数比平方和 `Σ[ln(预测/实测)]²`（相对误差、对称、跨数量级）
- 预测区间：两层误差合成（参数不确定性 × 自由度校正 + 测量噪声 ÷ √k），分位数取 t 分布

[写一句：为什么用 t 分布而不是正态]
